# Archived, sanitized example

This directory preserves the already executed experimental example: initial reference 0001, R&B frame 6544 and B frame 6545. All ten explanatory figures, the HTML/Markdown guide, phase/review maps, saturation values and source-image SHA256 hashes are retained.

Computer-specific paths in JSON, CSV, HTML and Markdown have been replaced by repository-relative paths. The settings shown inside these reports are historical documentation; use the root settings.py to run the program.

This is a static example for inspection, not a resumable run. The original batch_manifest.json and pair_complete.json resume markers are deliberately excluded because their fingerprints bind the original machine paths and file timestamps. No replacement resume fingerprint has been fabricated. Run the bundled demo to create a new resumable result under results/.

The numerical phase and saturation results and the scientific image pixels are unchanged by this cleanup. Relative report links continue to use this directory and its figures/ subdirectory.
